# Scenariu 5 · Documentează · 50 XP

## Situația

Repo-ul are un README general, dar nimeni nu a documentat ce ai învățat rezolvând scenariile.

## Ce faci

1. Scrie un `README.md` nou pentru copia ta: ce e repo-ul, ce scenarii conține și, pe scurt, cum ai rezolvat fiecare (o frază + comanda principală).
2. Scrie primul ADR al repo-ului, `docs/adr/0001-revert-vs-reset.md`: de ce ai ales comanda pe care ai ales-o la scenariul 2. Formatul:

   ```markdown
   # ADR-0001: <decizia, într-un rând>

   ## Context
   ## Decizie
   ## Consecințe
   ```

## Ce predai

- Un branch `docs/readme`, creat din `scenariu-5`, cu `README.md` și `docs/adr/0001-revert-vs-reset.md`
- Pull Request `docs/readme` → `scenariu-5`, cu titlul `Scenariu 5: ...`
